### AI Security Track 学习笔记

输出了 [2026-06-07-ai-security-track.md](../notes/week4-project/2026-06-07-ai-security-track.md)，覆盖 6 个核心主题：

1. **Prompt Injection 防御** — Agent 输出 ≠ 直接执行，Guard 层用纯函数做确定性校验
2. **权限隔离** — 七维约束引擎，权限不是二元开关

4. **签名前模拟** — eth_call + gas 预估并行，风险三级分级
5. **两层守卫** — 硬约束自动拒绝 + 软约束人工确认
6. **纵深防御金字塔** — Permission → Guard → Simulation → Confirmation

每个主题都对照了项目中的实际代码文件和关键设计决策。

## 关键洞察

回头看项目代码，发现几个当时「直觉上觉得应该这样做」的设计，其实对应了 Handbook 的安全原则：

- **Guard 层不调 LLM**：当时设计是「Guard 应该是纯规则检查，不需要 AI」——现在看这是防止 LLM 判断 LLM 输出的正确做法
- **Simulation 结构化渲染**：不让 Agent 用自然语言总结风险——现在看这是防止幻觉掩盖真实风险
- **Session Key 绑定 Policy**：密钥和权限一体创建——现在看这是最小权限原则的实现
