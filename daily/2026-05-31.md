## 对我最重要的三个概念

1. **Session Key ≠ 钱包**：Session Key 是"打了权限标签的临时密钥对"——有过期时间、有金额上限、有白名单约束。Agent 拿的不是钱包私钥，是一个受限的临时授权。
2. **安全是设计出来的，不是事后加的**：Safe Guard 的硬约束在代码层拦截，灰区升级到人——这个"能做的人工不拦，不能做的代码直接不给过"的设计原则贯穿整个系统。
3. **概念先行 + 最小实践有效**：两周前我对 AI、Web3、编程都是零基础。每个概念配一个最小实践（跑 Claude Code Prompt、签到 Sepolia 交易、写 PermissionPolicy 代码），能真正理解，不是纸上谈兵。
