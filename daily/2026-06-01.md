## 完成事项

### 1. 创建 `agent-wallet.ts` — 权限层与执行层的桥接模块

架构：

```
Agent 提议交易
  → Safe Guard（硬约束拦截 + 灰区升级）
  → Session Key（权限策略校验）
  → PimlicoClient（gas 价格 + paymaster 赞助）
  → SimpleSmartAccount（链上执行）
  → Sepolia（真实交易确认）
```

关键实现：
- `initAgentWallet()`: 初始化 Smart Account + Pimlico Client（bundler + paymaster 合一）
- `agentExecuteTransaction()`: Safe Guard 前置校验 → 获取 gas 价格 → 提交链上（含 paymaster 赞助）

### 2. 新增 Step 7 链上执行场景

### 3. 踩坑记录：permissionless API 版本兼容

- 已安装的 `permissionless@0.2.57` / `0.3.x` 中，`signerToSimpleSmartAccount` → `toSimpleSmartAccount`，`ENTRYPOINT_ADDRESS_V07` 不存在
- Pimlico v2 API 不支持标准 `eth_estimateUserOperationGas`，需用 v1 API
- v1 API 要求 `maxFeePerGas` / `maxPriorityFeePerGas` 必须预填充，不能留空给 bundler 估算
- `sendUserOperation` 需显式传 `paymaster` 参数才能启用赞助
- `createPimlicoClient` 已经是 bundler + paymaster 合一，无需分开创建

## 项目总结

从零基础到完成一个可运行的 Agent Wallet 三层架构：

```
Safe Guard（前置拦截）→ Session Key（权限签名）→ Smart Account（链上执行）
```

- **权限层**：七维策略（资产白名单、单笔上限、日累计、合约白名单、函数选择器、时间窗口、频率限制）
- **安全模型**：硬约束（代码直接拒绝）+ 软约束（灰区升级人工确认）
- **链上执行**：ERC-4337 Smart Account + Pimlico Bundler + Paymaster Gas 赞助
- **代码量**：~400 行 TypeScript，6 个模块
