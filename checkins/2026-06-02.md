**今日学习**：

在 Safe Agent Wallet 中实现了 Pre-transaction Simulation 模块——在执行交易前，通过 eth_call 链上模拟 + Pimlico bundler gas 预估，生成结构化 SimulationReport，按 riskLevel（low/medium/high）分级确认。low 自动通过，medium/high 弹终端 y/n 确认。

**核心收获**：

1. **"模拟 → 确认 → 执行"的安全闭环**：在 Safe Guard 拦截之后、链上执行之前，插入一步让用户看到"到底会发生什么"——余额变化、gas 费用、是否会 revert、风险等级。用户可以对比"Agent 说的"和"链上模拟实际会发生的"是否一致，再决定是否执行。

2. **riskLevel 聚合指标的设计**：不是简单展示原始数据，而是综合 callSim 成败、余额充足性、gas 占比，给出一个 low/medium/high 的判断，让上层（CLI/前端）无需重复计算就能决定是否弹确认框。

3. **循环依赖的 duck-typing 解决方案**：`pre-tx-sim.ts` 需要访问 wallet 的方法但不应 import `agent-wallet.ts`（后者也要 import 前者）。通过定义本地最小接口 `SimWallet`，只声明需要的方法签名，运行时 `AgentWalletInstance` 自动满足，无需显式 implements。
